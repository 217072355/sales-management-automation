# Sales Management Automation

This project automates the management of sales data using Excel. It allows users to:
- Add new products
- Update prices
- Search product records
- View and generate sales reports
- Backup the data file automatically

## Features
- Uses `openpyxl` to interact with Excel files
- Easy command-line interface
- Useful for small businesses and inventory tracking
